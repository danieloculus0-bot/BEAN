Built for quality engineers

A structured workflow for dimensional inspection.

Keep the print, the characteristic, and the inspection record tied together. The desktop application does the extraction and document generation; the quality engineer reviews the results before use.

01 / IMPORT

Open a drawing

Load a PDF and an FAI template in the Python desktop interface.

02 / EXTRACT

Find characteristics

Extract candidate dimensions using PDF text, with optional offline OCR and tolerance detection.

03 / REVIEW

Correct what matters

Edit the characteristic table and verify nominal sizes, tolerances and annotations.

04 / EXPORT

Generate the package

Produce a ballooned drawing PDF and editable FAI Excel workbook for inspection use.
