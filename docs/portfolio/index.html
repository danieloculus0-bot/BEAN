The fine print matters

Real projects. Honest boundaries.

These projects include released source, browser demos, local beta software, experimental research and architecture plans. A browser simulation does not imply access to an actual ERP, wallet, physical robot or engineering solver. CI receipts are evidence for the specific jobs and commits they tested, not a blanket production certification.

The repositories are public to inspect. Public visibility does not automatically grant redistribution rights. Check the license in each repository before reuse. For current build evidence, follow each project's README and GitHub Actions.
