# Breakout multi-seed replication, October 11, 2026

**Disposition: NO REPLICATED NET GAIN.** This is a separate Q-learning parameter-search prototype, not evidence of BEAN Core self-directed learning.

## Prior result
One fixed training RNG seed selected a learning configuration yielding 12.04 vs 11.88 bricks/game on 800 paired holdout games, a +0.16 advantage. The narrow interval previously reported was conditional on that seed and must not be generalized across independent training runs.

## Fresh replication (new RNG seeds)
Compared fixed hyperparameters (alpha=0.23, gamma=0.975, exploration floor=0.025) against candidate (alpha=0.35, gamma=0.99, exploration floor=0.025). Three independent training RNG seeds, 900 games each; separate 50-game validation selection and 200-game fresh paired holdout per training seed. **Selected minus fixed:**

| Training seed | Selected config | Holdout selected | Holdout fixed | Delta |
| --- | --- | ---: | ---: | ---: |
| 1701 | Alternative | 3.18 | 3.44 | -0.26 |
| 1702 | Fixed | 10.915 | 10.915 | 0.00 |
| 1703 | Fixed | 12.07 | 12.07 | 0.00 |

Mean across training seeds **-0.0867** bricks/game. Seed-cluster bootstrap 95% interval **[-0.26, 0.00]**, based on just three seeds and not definitive. The strategy search failed to generalize this time. The original positive run is preserved rather than invalidated or erased.

The longer eight-seed, six-candidate attempt exceeded execution time without returning a result. The reduced run compared only two configurations, not the original six. This is an intentionally narrow replication, not a final verdict on all strategies.

## Next experiment
Repeat with more independent training seeds, full six-way selection using validation only, a preregistered untouched holdout, paired estimates that cluster by training seed, and a fixed compute budget. Separately test real BEAN Sponge TD learning and score-before-file memory capsules. Do not promote a strategy from training or validation performance alone.
