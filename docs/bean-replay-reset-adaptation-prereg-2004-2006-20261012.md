# Preregistration: stale-replay reset on task reversal, synthetic seeds 2004–2006 (2026-10-12)

**Status at registration:** not run. This is a research-only adaptation and retention experiment, not a superiority contest or evidence of autonomous general intelligence. Branch forked from completed reward-shift experiment commit `70bdcbd634abcf918461073c02237280480aecde`. Base neural learner `bean/optimization/sponge_dqn.py` and task `experiments/sponge_breakout/reward_shift_adaptation.py` are frozen. New harness code only; no change to Main.

## Question and intervention

After learning rule A, does discarding stale replay transitions at the moment the reward mapping changes improve adaptation to rule B, relative to preserving replay? The **only** experimental intervention is `learner.replay.clear()` immediately after the switch. The online network, target network, Adam optimizer, learning clock, random state, epsilon and reward generator must otherwise be identical at the switch. This isolates one bounded learning-memory intervention, not architectural superiority. We explicitly track forgetting of A and count frames and gradient updates so that a short-term gain is not confused with general growth.

## Preregistered task and budgets

Independent synthetic seeds **2004, 2005, 2006** are allocated only to this experiment. They are not Breakout seeds and have not been used in the prior reward-shift trial (2001–2003). Do not substitute or retest as pristine after first execution. For each seed: context `(x, flag, distractor)` where x is uniform integer 0..14, flag and distractor are independent binary values; three actions. Rule A correct action is `(x // 5 + flag) % 3`, rule B is `2 - A`; for A=1 the correct action is unchanged. Reward +1 for correct, -1 otherwise, terminal transitions. Fixed network `SpongeDQN` with batch_size 32, replay_capacity 5000, warmup 64, learn_every 2, target_sync 100, lr 0.0007, gamma 0.99, epsilon 0.15.

Train one shared A learner for **2400** interactions. Snapshot full learner state, then construct two independent copies from that same state. Arm RETAIN keeps the 2400 A replay samples (capped at 5000); arm RESET clears only replay. Both receive the **same pre-generated sequence of 1800 B contexts and labels**; use the same initial policy and exploration RNG state. Frozen-A and cold untrained policies are non-learning measurement controls. All model selection is forbidden; no stopping, tuning or arm changes based on scores. No additional B training outside the fixed 1800 steps.

Pre-switch A and B diagnostic accuracy, then B and A diagnostic accuracy at B steps **0, 300, 600, 900, 1200, 1500, 1800** on a fixed, repeatedly viewed 300-context set (not confirmatory). Validation domain `50000 + seed`; training domain `10000 + seed`. At completion, generate exactly one previously unopened **600-context** paired evaluation set per seed from `70000 + seed`. Measure B accuracy for RESET, RETAIN, frozen-A and cold; A accuracy for RESET, RETAIN and frozen-A. The primary per-seed delta is **RESET minus RETAIN B holdout accuracy**. Secondary measures: A retention, within-arm B gain relative to step zero and frozen-A, learning-curve area (mean of seven diagnostic B accuracies), frame/update counts, initial/final SHA256 model fingerprints, and reload-equivalence of saved weights in a separate process. Preserve model weights, results, hashes and all negative outcomes.

## Gates, analysis and interpretation

Before opening seeds 2004–2006, run Python 3.12 CPU PyTorch protocol tests on both Windows and Linux, using only synthetic toy states and/or previously seen seed 2001. These tests must confirm identical switch-state hashes, deterministic context generation, replay-only intervention, restart prediction equivalence and output integrity. If either gate fails, **do not** open fresh holdouts. Run three independent seed jobs only after both pass. Each job runs both arms together, preserving paired conditions.

Report all three raw deltas, arithmetic mean, sample SD and Student-t 95% CI using n=3 independent seeds (OS repeats are not new independent samples). Report diagnostic curves, cold/frozen controls, A-retention costs, budgets and hashes. If any paired-control pre-switch hash differs, invalidate the comparison. A positive delta alone is not proof of longitudinal growth, transfer, self-directed improvement or general intelligence. Repeatedly viewing diagnostic contexts limits their independence. No code tuning on opened holdouts. Any follow-up must be separately preregistered with untouched seeds and independently reviewed. No Main merge, trading, hardware actions or external publication claims.
