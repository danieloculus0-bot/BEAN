Persistent memory. Measurable experimentation. Independent scrutiny.

A brain worth testing.

BEAN, the Behavior Enabled Avatar Node, is an experimental model-independent cognitive architecture that carries history between sessions, proposes actions, tests hypotheses, keeps what survives evaluation, and records what fails. It has real software, real model runs and meaningful unfinished work.

Source review: November 20, 2026

What's new in the source

Original drawings, with the misses intact

The Python Core ran real local Ollama Qwen2.5:3b drawing sessions. The model selected subjects and geometry. Four live-model artifacts and two synthetic fixtures appear in the gallery index. A failed underwater-forest session is retained. Artifact authenticity is supported by run receipts, but drawing quality and learning gains have not been established.

Plans that survive a restart

Ordered, persisted Core plans can release each step only after the previous one completes. Failed and unverified prerequisites do not silently advance. A synthetic Core evaluation exercises interruption, resumption and withheld-query feedback. This is not autonomous invention of new plans.

Locally executed language inference

On November 1, the Jetson Orin Nano Super completed local Qwen inference, Core event recovery and an operator-observed boot run. New CPU smoke tests now reject factually incorrect answers instead of treating a well-formatted response as success. Jetson speech, vision and motors are not demonstrated as one deployed end-to-end stack.

Review before action

BEAN has a local SQLite-backed challenge preflight that stores objections, linked evidence, blocking decisions and explicit overrides. It is a caller-invoked gate, not a GitHub-enforced approval system or independent truth machine.

What needs evidence next

  • Artistic development: complete blinded pixel evaluation and adaptive-versus-frozen-memory drawing controls, with retained failure cases.
  • Autonomous capability: show independently chosen tasks, validated outcomes, durable skill retention and useful transfer to unfamiliar domains.
  • Cognitive challenge: wire the local preflight into actual effectful host actions and measure whether evidence-grounded objections improve decisions.
  • Embodiment: join Jetson inference, speech, perception and motion through a tested, inspectable Core control loop.
  • Third-party replication: independently reproduce key findings using the exact revision, fixtures and scoring criteria.

One project, several distinct systems: BEAN Python Core, the hosted BEAN notes companion, the Perplexity evidence MCP, Axiom and AIscend do not share one automatically synchronized memory or execution environment. A public demo can be synthetic even when the underlying Core supports real runs. No claim of AGI or consciousness is made.
