Want to test the real Python/SQLite memory?

The actual BEAN Core restart-continuity test opens its SQLite memory, records an event and review-required proposal, closes, then reopens and verifies survival. It runs locally with a mock provider and disposable data.

A real BEAN MCP developer preview exists, with four bounded read-only tools. It is not yet a publicly hosted ChatGPT connector and cannot store users' remote chat memories. A no-login, cross-device service would require a hosted Core instance, session isolation, abuse controls, and a privacy/retention policy.
