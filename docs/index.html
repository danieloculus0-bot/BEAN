Reasoning needs a memory. Evidence needs a history.

BEAN is an experimental persistent reasoning architecture that records events, preserves uncertainty, traces proposals to their context and keeps actions separate from model output. The reasoning provider can change. The evidence record remains inspectable.

Explore BEAN on GitHub Run the offline demo

What the project actually implements

Persistent event history

SQLite-backed sessions and events, recorded observations and trace IDs that a host application can inspect.

Evidence and uncertainty

Epistemic checks, contradiction handling, hypotheses and N/A-aware report adapters with explicit limits on source trust.

Reviewable reasoning

Model adapters provide reasoning proposals. Hosts retain policy, execution authority, and the ability to reject a proposal.

Reproducible experiments

Cross-platform tests, research branches, synthetic benchmark comparisons, and documented negative results.

Start with real code

A local, offline five-minute demonstration

Python 3.10+, Git and psutil. No API key, connected machine or data upload. This demonstrates event logging and proposal boundaries using a mock reasoning provider.

git clone https://github.com/danieloculus0-bot/BEAN.git
cd BEAN
python -m pip install psutil
python -m examples.quickstart_reasoning

Evidence over hype

Read the experiments, including what failed

The research index links source branches, findings, workflow runs and limitations. Some studies use intentionally fictional cases. Their results are not claims of AGI, independent source authentication, production autonomy, or measured superiority on the live web.

Research index Python integration Core and Bridge evidence flow Cross-platform regression runs

Current project scope: experimental development with review-required proposals. Live ERP integration, independently validated open-world learning, and robot autonomy are not claimed. Public source access is not a redistribution license.

Integrate, inspect, contribute

The BEAN AI Bridge is a separate generic ERP/KPI evidence and replay prototype using synthetic test data. BEAN Core supplies persistent reasoning primitives. Have a concrete use case or a reproducible failure? Open a GitHub issue.
