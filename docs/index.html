Meet BEAN · Behavior Enabled Avatar Node

What if AI could learn from yesterday?

BEAN is an AI agent project designed to give artificial intelligence something resembling experience. A memory of what happened, a way to check its work, and a chance to make better decisions next time.

Because getting an answer is useful. Remembering whether it actually worked is even better.

Little name. Big idea. Built for the long game.

The simple version

AI answers questions. BEAN is trying to learn from what happens next.

Most AI assistants are pretty good at answering you right now. But what happens when the answer is wrong? Or you find a better way? Or you come back next week?

BEAN is being built around memory, evidence and feedback so AI can build on earlier work instead of starting from scratch every time.

Without useful history

“Try this fix.” You try it. It fails. Tomorrow the assistant may suggest the very same thing.

What BEAN is working toward

“We tried that already. It didn't work. Here's what we learned, and here's the next idea worth testing.”

That's the project goal, not a promise that every app connected to BEAN works this way today.

Four things that matter

Less starting over. More getting somewhere.

01 / Remember

Keep useful history

Keep track of notes, decisions and results. Some BEAN memories already survive a restart.

02 / Check

Ask, “How do we know?”

Compare claims, look at sources and flag when an answer needs more evidence.

03 / Adjust

Learn from results

In specific tests, BEAN can score outcomes and change how it makes choices. Broader learning is still research.

04 / Work together

Help other AI systems

BEAN is intended to work with language models and tools, not replace everything already doing its job.

Here's an easy way to picture it

Think of a mechanic who keeps good service records.

A mechanic who remembers what you fixed last month is more useful than one who acts like you've never met. That's the kind of continuity BEAN is designed to help AI build.

Say you're troubleshooting a machine...

1. Try an idea.

Pick a possible fix and keep track of why it seemed worth trying.

2. Check the result.

Did it work? Did it make things worse? What evidence do you have?

3. Use the lesson.

Next time, look up what happened instead of guessing all over again.

This is an everyday example of the idea, not a claim that BEAN is already connected to your equipment.

The reality check

What actually works today?

There's working code and measured research behind BEAN. But the full vision is still being built.

Built in local Python Core

Memory and decision tools

Persistent records, evidence-linked history, limited reasoning and feedback features, and source-aware web research with restrictions.

Tested in experiments

Learning on specific tasks

Training simple game agents, challenging reasoning approaches and comparing outcomes. Some tests improve, and some don't.

Still in development

Making it all work together

The local Core, separate research branches and small hosted connector aren't yet one seamless general-purpose intelligence.

Important: BEAN hasn't been shown to be artificial general intelligence (AGI), conscious or a universally self-improving AI. The code and recorded experiments are open for inspection.
One real learning experiment

Did it get better, or just get lucky?

In a simple brick-breaking game, a trained BEAN learning system cleared more bricks than the untrained version when both were tested on games they hadn't trained on.

That's measurable learning on one specific task, not proof it could automatically master racing, manufacturing or anything else.

Good questions

Before the hype gets carried away.

Is BEAN another ChatGPT?

No. BEAN is a separate experimental AI agent project. It can work alongside language models, but it's not a replacement for an entire language model.

Is BEAN alive or self-aware?

There's no evidence that BEAN is conscious or alive. This project studies memory, reasoning, feedback and learning as software capabilities.

Can I use BEAN today?

The code is publicly viewable on GitHub. The limited hosted BEAN connector can retain and recall notes, but it is not the same thing as the larger local Python Core. Running the full research software takes technical setup.

Does BEAN actually learn?

Some experiments show measurable learning on defined tasks, and parts of the Core store feedback and decisions. That does not yet mean broad, continuous improvement across everything an AI does.
