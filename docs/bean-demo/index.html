What this actually means

GitHub Actions temporarily runs BEAN's real Python process, restores its two SQLite files, handles digital Core maintenance, and commits a checked continuation.

The runner is not continuously awake. GitHub's artificial Core memory and the private Jetson Core remain separate. A successful boot is evidence of runtime continuity, not consciousness, training progress, or a live personal conversation.

The ChatGPT issue bridge is an asynchronous public transport. Never place passwords, private chats, personal memories, employer material, or customer data into these public issues.

Why dictionary patching matters
For a small ledger, snapshots plus field-level patches can avoid saving an entire state for every observation. Deterministic replay reconstructs the active state, and hashes can validate archived evidence.
Use a bounded active working memory, immutable event history, occasional snapshots and a verified rebuild path. Prefer ordinary compressed SQLite for the actual Core until matched experiments prove a new format beats it.
Patch savings shown here use UTF-8 JSON bytes, not compressed on-disk SQLite, so they are illustrative only.
