BEAN: an intelligence layer for existing AI models.

Behavior Enabled Avatar Node (BEAN) is a research software platform designed to strengthen AI agents and language models through retained experience, evidence-linked reasoning, feedback, and reusable strategies. It is not simply another conversational interface or a new pretrained foundation model.

Explore BEAN Core Inspect learning experiments

What is implemented?

Persistent learning context

SQLite-backed memory, SHA-linked evidence trails, journal recovery, and model-independent history.

Model assistance

Reasoning service, language-model provider adapters, evidence review, explicit uncertainty, and advisory action screening.

Feedback and adaptation

Outcome receipts, matched reward scoring, contextual strategy selection, neural and Q-learning experiments.

Reproducibility

Source-linked tests, retained failures and baseline comparisons. Inspect current checks rather than relying on marketing claims.

Who might use BEAN?

Researchers studying persistent reasoning or agent learning; developers building AI assistants that need recoverable memory and evidence; teams exploring model-agnostic decision support; and organizations interested in evaluating bounded integrations or prototypes.

What is not yet established?

BEAN has not demonstrated frontier-model-level standalone reasoning, general-purpose independent transfer, assured autonomous reliability, or consistently superior performance on held-out tasks. Hosted plugin functionality is narrower than the full Python Core. Tested mechanisms and scientific outcomes should be evaluated separately.
