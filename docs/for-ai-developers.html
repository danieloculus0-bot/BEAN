For builders, tinkerers and developers

Want to build with BEAN?

BEAN is a Python AI project built to give other AI systems something useful: a record of what happened, a way to check their work and a chance to make better decisions next time.

The main website explains the idea in everyday language. This page is for people who want to get under the hood.

What can you build on today?

Records that survive

BEAN Core can keep useful history locally, including where information came from. Under the hood, it uses SQLite storage and a recoverable journal.

Help for AI models

Optional language models can use tools for comparing information, reviewing claims and identifying uncertainty. BEAN is not a replacement language model.

Learning experiments

Try defined tasks where the system receives feedback and adjusts choices. Game-learning and strategy experiments have measurable results.

Tests, including the ugly ones

Find repeatable tests, comparison groups and records of failures. A passing test proves that test worked, not that we invented AGI.

Who is this useful for?

People building personal assistants, experimenting with AI memory, creating practical decision tools or checking whether a new AI idea actually improves results. If you like to tinker, you are in the right place.

What should you not expect yet?

BEAN is not a finished general-purpose AI. It has not demonstrated independent mastery of unrelated fields, guaranteed reliability or consistent superiority over other approaches. The smaller hosted connector is not the full Python program, and separate research branches are not automatically running together.

Show me the proof

  • GitHub Actions: source revision and regression checks
  • Model-facing evidence and claim assessment adapter
  • Measured outcome and learning feedback
  • Original versus updated BEAN paired Breakout experiment

Want to build something together?

Bring a real problem, a test or an idea. Open a GitHub issue to discuss collaborations and improvements. The code is public to inspect, but that does not automatically grant permission to reuse it. Check the licensing terms before doing so.
