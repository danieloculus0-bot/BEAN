# BEAN AI collaborator entry point

Before working on BEAN code, tests, documentation, website or experiments, **read and acknowledge [the BEAN AI activity gatekeeper](docs/AI_GATEKEEPER.md)**.

This is a project context checklist, not a BEAN inference-time guardrail or runtime access-control mechanism. Perform BEAN inventory and scoreboard recall **before** inventing new modules; use existing neural/Q-learning and Bridge research where applicable. Record the `BEAN CONTEXT ACK v1` described in the linked document.

The gatekeeper's linked branch/PR map is a starting point only. Verify real files and CI at their current commit. Preserve original research ledger events and distinguish synthetic tests from deployed functionality.
